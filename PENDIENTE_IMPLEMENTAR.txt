    1. Aprendiz acerca el llavero al lector → POST con codigo_llavero
    2. Buscar Usuario por codigo_llavero (getByCodigoLlavero)
    3. Buscar la sesión activa de la Ficha del aprendiz (getSesionActiva)

       registrado_por=(sistema/admin), codigo_llavero (snapshot)
    7. Calcular minutos_retardo = MAX(0, hora_entrada - sesion.hora_inicio)
    8. Retornar JSON con resultado (para mostrar en pantalla del lector)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. El instructor/admin descarga una plantilla Excel (.xlsx) desde el sistema.
  2. Completa la plantilla con las sesiones del semestre (una fila = una sesión).
  3. Sube el archivo al sistema a través de un formulario.
  4. El servidor procesa el Excel fila por fila y genera registros en la
     tabla 'sesion' de la base de datos.
  5. El sistema muestra un resumen: sesiones importadas, filas con error,
     sesiones duplicadas omitidas.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  B.2 — ESTRUCTURA DE LA PLANTILLA EXCEL (.xlsx)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  El archivo Excel debe tener exactamente una hoja llamada "Horarios".
  La fila 1 son los encabezados (no se importa).
  Cada fila siguiente representa una sesión de clase.

  COLUMNA | ENCABEZADO       | TIPO        | EJEMPLO              | OBLIGATORIO
  ─────── | ──────────────── | ─────────── | ──────────────────── | ───────────
  A       | fecha            | YYYY-MM-DD  | 2026-08-04           | SÍ
  B       | hora_inicio      | HH:MM       | 07:00                | SÍ
  C       | hora_fin         | HH:MM       | 13:00                | SÍ
  D       | competencia      | Texto       | Bases de datos        | SÍ
  E       | instructor_email | Email       | ana@sena.edu.co       | SÍ
  F       | estado           | Texto       | Activo               | NO (default Activo)

  Notas de la plantilla:
  - La Ficha se selecciona en el formulario de carga (no va dentro del Excel).
  - La columna 'competencia' debe coincidir EXACTAMENTE con el nombre en BD.
  - La columna 'instructor_email' debe coincidir con el email de un usuario
    con Rol_id = 1 (Admin) o Rol_id = 2 (Instructor) en la BD.
  - Las fechas deben estar dentro del rango del semestre seleccionado.
  - Si una fila tiene fecha + hora_inicio + ficha que ya existe en BD,
    se omite (no duplica) y se cuenta como "ya existente".

  Ejemplo de filas válidas:
  ┌────────────┬─────────────┬──────────┬───────────────────────┬───────────────────────┬────────┐
  │ fecha      │ hora_inicio │ hora_fin │ competencia           │ instructor_email       │ estado │
  ├────────────┼─────────────┼──────────┼───────────────────────┼───────────────────────┼────────┤
  │ 2026-08-04 │ 07:00       │ 13:00    │ Bases de datos        │ ana@sena.edu.co        │ Activo │
  │ 2026-08-05 │ 07:00       │ 13:00    │ Lógica de programación│ ana@sena.edu.co        │ Activo │
  │ 2026-08-07 │ 13:00       │ 19:00    │ Bases de datos        │ pedro@sena.edu.co      │ Activo │
  └────────────┴─────────────┴──────────┴───────────────────────┴───────────────────────┴────────┘

  B.3 — VALIDACIONES REQUERIDAS AL IMPORTAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  VALIDACIÓN DEL ARCHIVO:
  - El archivo debe ser .xlsx o .xls (no .csv, no .ods).
  - Tamaño máximo del archivo: 5 MB.
  - La hoja activa debe llamarse "Horarios" (o ser la primera hoja).
  - El número de filas de datos no debe superar 500 por importación.
  - La fila 1 debe tener los encabezados esperados (validar nombres exactos).

  VALIDACIÓN DE CADA FILA:
  - fecha:         formato YYYY-MM-DD, debe ser una fecha válida del calendario.
  - fecha:         debe estar dentro del semestre seleccionado en el formulario.
                   (fecha >= semestre_inicio AND fecha <= semestre_fin)
  - hora_inicio:   formato HH:MM, 00:00 – 23:59.
  - hora_fin:      formato HH:MM, debe ser MAYOR que hora_inicio.
  - competencia:   el nombre debe existir en la tabla 'competencia' de la BD.
                   Si no existe → marcar fila como error y continuar.
  - instructor_email: debe existir en tabla 'Usuario' con Rol_id IN (1,2).
                      Si no existe → marcar fila como error y continuar.
  - estado:        si viene vacío → usar 'Activo' por defecto.
                   Solo acepta: 'Activo', 'Cancelado', 'Finalizada'.
  - Duplicado:     si ya existe una sesión con misma Ficha_id + fecha +
                   hora_inicio → omitir fila, no insertar, reportar como omitida.

  COMPORTAMIENTO ANTE ERRORES:
  - La importación es PARCIAL: las filas válidas se insertan aunque haya errores.
  - Al finalizar se muestra un reporte detallado fila por fila:
      ✅ Fila 2: Sesión creada correctamente.
      ⚠️ Fila 5: Omitida, ya existe una sesión para esa fecha y hora.
      ❌ Fila 8: Error — competencia "Redes" no encontrada en el sistema.
      ❌ Fila 12: Error — instructor "x@x.com" no existe o no tiene el rol correcto.

  B.4 — FORMULARIO DE CARGA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Campos del formulario de importación:

  1. Ficha:           <select> → obligatorio. Determina a qué ficha pertenecen
                       las sesiones del Excel.

  2. Semestre (desde):<input type="date"> → fecha de inicio del semestre.
                       Ejemplo: 2026-08-01

  3. Semestre (hasta):<input type="date"> → fecha de fin del semestre.
                       Ejemplo: 2027-01-31
                       Validación: hasta >= desde, rango máximo = 6 meses (184 días).

  4. Archivo Excel:   <input type="file" accept=".xlsx,.xls">
                       Validación: tipo MIME, tamaño ≤ 5 MB.

  5. Botón "Descargar Plantilla": enlace que descarga el archivo Excel de
                       ejemplo con encabezados correctos y 3 filas de muestra.

  6. Token CSRF:      <input type="hidden"> protección contra CSRF.

  B.6 — LÓGICA DE PROCESAMIENTO DEL EXCEL (pseudocódigo)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  procesar():
  ───────────
  $fichaId      = (int) $_POST['ficha_id']
  $semInicio    = $_POST['semestre_inicio']   // YYYY-MM-DD
  $semFin       = $_POST['semestre_fin']      // YYYY-MM-DD

  // Validar rango semestral (máx 184 días)
  if (days_between($semInicio, $semFin) > 184) → error

  // Cargar Excel
  $xlsx = SimpleXLSX::parse($_FILES['archivo']['tmp_name'])
  $rows = $xlsx->rows()  // Array de arrays (fila 0 = encabezados)

  $resultado = [creadas=0, omitidas=0, errores=[], detalles=[]]

  foreach ($rows as $index => $row):
    if $index == 0: continue  // saltar encabezados

    $fecha       = trim($row[0])   // col A
    $horaInicio  = trim($row[1])   // col B
    $horaFin     = trim($row[2])   // col C
    $nombreComp  = trim($row[3])   // col D
    $emailInst   = trim($row[4])   // col E
    $estado      = trim($row[5]) ?: 'Activo'  // col F

    // Validaciones de fila
    if NOT valid_date($fecha):
      agregar a errores: "Fila $index: fecha inválida"
      continue

    if $fecha < $semInicio OR $fecha > $semFin:
      agregar a errores: "Fila $index: fecha fuera del semestre"
      continue

    if NOT valid_time($horaInicio) OR NOT valid_time($horaFin):
      agregar a errores: "Fila $index: hora inválida"
      continue

    if $horaFin <= $horaInicio:
      agregar a errores: "Fila $index: hora_fin debe ser mayor que hora_inicio"
      continue

    // Buscar competencia por nombre
    $competencia = Competencia::getByNombre($nombreComp)
    if NOT $competencia:
      agregar a errores: "Fila $index: competencia '$nombreComp' no encontrada"
      continue

    // Buscar instructor por email
    $instructor = Usuario::getByCorreo($emailInst)
    if NOT $instructor OR $instructor['Rol_id'] NOT IN [1,2]:
      agregar a errores: "Fila $index: instructor '$emailInst' no válido"
      continue

    // Verificar duplicado
    $existe = Sesion::existeSesion($fichaId, $fecha, $horaInicio)
    if $existe:
      $resultado['omitidas']++
      agregar a detalles: "⚠️ Fila $index: omitida, sesión ya existe"
      continue

    // Insertar sesión
    Sesion::create([
      Ficha_id       => $fichaId,
      Competencia_id => $competencia['id'],
      Instructor_id  => $instructor['id'],
      fecha          => $fecha,
      hora_inicio    => $horaInicio,
      hora_fin       => $horaFin,
      estado         => $estado
    ])

    $resultado['creadas']++
    agregar a detalles: "✅ Fila $index: sesión creada para $fecha $horaInicio"

  endforeach

  // Eliminar archivo temporal
  unlink($_FILES['archivo']['tmp_name'])

  // Pasar $resultado a la vista
  require_once ROOT_PATH . '/views/importar/horarios_resultado.php'
